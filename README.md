# C Programming Journey

A structured collection of my C programming exercises, memory management implementations, and algorithmic problem-solving practice.

## Topics Covered
- **Pointers & Dynamic Memory:** Pointer arithmetic, `malloc`, `calloc`, `realloc`, and `free`
- **Arrays & Strings:** 2D matrix operations and custom string manipulation
- **Recursion & Algorithms:** Searching (Linear, Binary) and Sorting (Bubble, Selection, Insertion)
- **Structures & File I/O:** Custom data records and file handling (`fopen`, `fprintf`, `fscanf`)
